# Privacy

Stitchy Mobile has no account system, analytics, telemetry, advertising, or
remote pattern-processing API.

- Imported files are processed inside the browser.
- Projects and progress are stored in the browser's local IndexedDB database.
- The hosting provider receives ordinary requests for public application files
  such as HTML, JavaScript, CSS, icons, and the original bunny demo.
- The hosting provider does not receive patterns selected through the file
  picker.
- Export creates a local download chosen by the user.

Removing the site's browser data removes locally stored Stitchy projects from
that browser. Export a backup first if the progress should be retained.
